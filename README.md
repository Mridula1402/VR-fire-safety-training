# VR-fire-safety-training
VR Fire Safety Training

About the Project

VR Fire Safety Training is an interactive web-based platform designed to educate users about fire hazards, prevention methods and emergency response procedures.

Objectives

- Create awareness about fire safety.
- Educate users about different types of fires.
- Explain fire prevention and protection methods.
- Teach users how to respond during fire emergencies.

Features

- Fire safety awareness.
- Fire hazard identification.
- Fire extinguisher information.
- Emergency response guidelines.
- Interactive learning experience.

Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

Future Enhancements

- 3D virtual reality simulations.
- Interactive fire evacuation scenarios.
- Fire safety quizzes.
- Voice-guided instructions.
